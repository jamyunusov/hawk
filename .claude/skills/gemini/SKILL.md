# Gemini

Скрипт: `.claude/skills/gemini/scripts/gemini.py` (только стандартная библиотека Python).

## Вызов

```bash
python3 .claude/skills/gemini/scripts/gemini.py "вопрос"
python3 .claude/skills/gemini/scripts/gemini.py -f src/app.py -f src/db.py "Найди баги в этом коде"
git diff | python3 .claude/skills/gemini/scripts/gemini.py   # промпт из stdin
python3 .claude/skills/gemini/scripts/gemini.py -m gemini-2.5-pro "сложная задача"
python3 .claude/skills/gemini/scripts/gemini.py --list-models
```

Опции: `-m` модель, `-f` файл в контекст (можно несколько), `-s` системная инструкция, `-t` температура.
Модель по умолчанию — `gemini-2.5-flash` (меняется через `GEMINI_MODEL`). Для сложных рассуждений и ревью бери pro-модель; актуальный список — `--list-models`.

## Правила

1. Gemini не видит репозиторий: передавай всё нужное через `-f` или stdin и формулируй задачу самодостаточно.
2. Не отправляй секреты (`.env`, ключи, токены, персональные данные) — проверь файлы перед `-f`.
3. Ответ Gemini — мнение другой модели, а не истина: сверь с кодом, прежде чем применять, и покажи пользователю, где вы с Gemini расходитесь.
4. Ключ: переменная `GEMINI_API_KEY`. В облачных сессиях Claude Code ключ хранится в секретах окружения и подставляется прокси автоматически. Ошибка 401/403 значит, что ключ не настроен — попроси пользователя добавить его, не пиши ключ в файлы.
